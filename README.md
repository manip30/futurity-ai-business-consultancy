# Futurity AI Business Consultancy

A new website for Futurity AI Business Consultancy, taking inspiration from the clear, outcomes-focused structure of the ADSP consultancy site while establishing Futurity's own brand, content, and positioning.

## Proposed stack

- **Next.js App Router + TypeScript** for a fast, search-friendly marketing site.
- **Tailwind CSS** for styling, with shadcn/ui where reusable accessible components are useful.
- **Sanity CMS** if the team needs to edit case studies, services, and articles without code changes.
- **Resend** for contact-form email if a form is in scope.
- **No database or AI provider is assumed** for the initial marketing site. Add integrations only when a confirmed feature needs them.

## Initial site direction

A useful first version could include:

- Home
- Services
- Case studies
- About
- Insights
- Contact

The exact pages and content will be confirmed before implementation.

## Open decisions

- Target customers, industries, and geographic market
- Core services and the outcomes Futurity wants to be known for
- Brand assets, visual direction, and writing tone
- Existing case studies, testimonials, and proof points that may be published
- Whether non-developers need to edit site content (CMS)
- Contact workflow: email, CRM, calendar booking, or another process
- Analytics and cookie-consent requirements
- Any interactive AI demonstrations or external AI APIs

## Development status

Repository and project outline are ready. App implementation begins after the initial content, brand, and integration decisions are agreed.
